# MediaForge 1.0.0

- Open a video, still image or image sequence in Media. Preview the original
  source, then trim, crop, reformat and export to a new destination.
- Use the timeline for frame navigation on eligible video sources. MediaForge
  keeps the source files intact when processing and exporting.
- Dub supported English video into Russian with the optional local Qwen3-TTS
  runtime and Aiden voice. Manage optional components in Settings.
- The Windows x64 portable bootstrap downloads pinned Python, Qt and FFmpeg
  directly from upstream after first-launch confirmation. Extract the whole
  ZIP to a writable local folder. Subsequent Media editing and export work offline.
- Settings manages appearance, storage and optional model installation.
  Keep `Data/v2` with the portable folder if you want to retain your profile.

Still-image processing supports PNG, JPEG, TIFF and static WebP within the
application's format and color limits. Optional AI components have separate
storage, availability and hardware requirements.
